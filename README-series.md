# Вычисление суммы ряда

Программа на C вычисляет сумму конечного ряда

```text
sum = Σ 1 / a^(2^i),  i = 0, 1, ..., n
```

Пользователь вводит значение `a` и целое число `n`. Затем программа перебирает `i` от `0` до `n` включительно, вычисляет знаменатель `a^(2^i)`, добавляет очередное слагаемое к сумме и выводит результат с точностью до шести знаков после запятой.


## Ввод программы

- `a` — основание степени, вводится как вещественное число.
- `n` — целое число; сумма включает слагаемые от `i = 0` до `i = n`.

Для корректных конечных результатов выбирайте значения `a` и `n`, при которых степени и деление не приводят к переполнению или делению на ноль.
